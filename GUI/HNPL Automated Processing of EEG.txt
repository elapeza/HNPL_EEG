Version Log number: 1.2.0
Release Date: 11/05/2026
Changelog:
- Fixed bug where selecting files on initialization tab would cause GUI to become inactive window
- Added feature to allow for resuming analysis steps after closing and reopening GUI by manually reopening datasets in EEGLAB and selecting the desired step on new Advanced tab. Resume step buttons bypass safe guards to prevent skipping steps in the processing order.
- Added toggle to allow datasets without ECG to be processed (Advanced tab)
- Added toggle to allow datasets without stimulation event markers to be processed (Advanced tab)
- Import data functionality improved to allow for registering bilateral stimulation recordings. In future updates, this will likely be streamlined to read from a config file to account for version drift and changing setup connections, as OTBiolab's conversion may export auxiliary channels in a strange order. Exact setup currently undecided and may be either .txt or .mat
- changed initialization check back end method. Functionality should be unchanged.
- Various quality of life and visual improvements

Version number: 1.1.0
Release Date: 9/25/2026
Changelog:
- Added Details tab to GUI to display details about GUI install
- Implemented changelog document to be automatically imported to Details tab
- Changed window title
- Fixed bug where epoch window did not update across tabs.
- Adjusted automatic dataset search to begin upon opening based on default folder (active folder in MATLAB)
- Split 'PostICA' function into Post-ICA merging of components onto datasets (PostICA) and epoching (Epoch) in order for ERPLAB compatibility
- Reduced tabs to be simpler. New tabs are: Initialization, Import Data, Epoch, Trial Rejection, Export, Details. Trial Rejection and Export remain placeholders.
- changed MATLAB call command to be eegapp instead of EEG_Processing_GUI for ease of access (EEGLAB does not need to be loaded first. this GUI will open it for you).
