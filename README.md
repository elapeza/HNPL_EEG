# HNPL_EEG
EEG analysis code for Human Neuromuscular Physiology Laboratory


Scripts adapted by Eli Lapeza from the original script written by Dr. Nathan Baune of the Neuroplasticity Research Laboratory at Emory University.
Significant changes have been made to allow for the main processing script to work with the setup used by the Human Neuromuscular Physiology Laboratory at the Georgia Institute of Technology
The most notable changes are going from BrainVision to OTBiolab and adjusting the EEG cap to be accurate.

This code is intended to be used with EEGLAB and MATLAB.
